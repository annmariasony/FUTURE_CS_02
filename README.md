# FUTURE_CS_02

## Phishing Email Detection & Awareness System
This repository contains the work completed for **Future Interns – Cyber Security Internship Task 2**.

### Project Objective
The objective of this project is to analyze phishing email samples, identify common phishing indicators, classify emails based on risk level, and provide practical cybersecurity awareness recommendations.
